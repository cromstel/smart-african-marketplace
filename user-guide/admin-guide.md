# Admin Guide

## Admin Dashboard

Access admin tools at `/admin/dashboard`.

## User and Role Management

- Create and manage users.
- Assign roles (customer, vendor, admin, salon owner).
- Activate/deactivate accounts as needed.

## Catalog Management

- Manage products, categories, tags, brands.
- Moderate content quality and listing consistency.

## Orders and Payments

- Monitor order lifecycle.
- Review payment statuses.
- Handle payment exceptions.

## Marketplace Manager

Use the `Marketplace Manager` sidebar menu in the admin panel to manage multivendor operations.

- Vendors: `/admin/vendors`
- Vendor verification: `/admin/vendor-verifications`
- Coupons: `/admin/coupons`
- Services (salon modules): `/admin/salons`, `/admin/salon-services`, `/admin/salon-stylists`, `/admin/salon-categories`
- Service bookings: `/admin/bookings`, `/admin/bookings/calendar`
- Subscription packages: `/admin/subscriptions/plans`, `/admin/subscriptions/subscribers`
- Marketplace finance: `/admin/refunds`, `/admin/payouts`, `/admin/withdrawals`
- Marketplace logistics: `/admin/shipping-settings`

## Subscriptions

- Configure plan catalog.
- Review subscriber lists.
- Monitor renewals and expirations.

## Content and Communications

- Manage pages, blog, announcements.
- Review campaign settings and tracking.

## Platform Settings

- Payment gateway credentials.
- Mail settings.
- Appearance and SEO settings.

## Security Operations

- Keep secrets out of version control.
- Rotate compromised keys immediately.
- Limit admin account usage and privileges.
