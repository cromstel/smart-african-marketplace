# Homepage Content Refresh Runbook

This runbook governs regular homepage merchandising and messaging updates.

## Refresh Cadence
- Weekly: hero banner relevance and CTA checks
- Bi-weekly: featured categories and vendor spotlight rotation
- Monthly: copy, campaign block, and trust signals review

## Update Checklist
- Ensure hero title/subtitle match current campaign priorities.
- Refresh featured products/categories to reflect active inventory.
- Validate all homepage CTAs route correctly.
- Remove expired promotions and stale references.

## Post-Update QA
- Desktop/mobile visual check
- Core Web Vitals regression spot check
- Broken-link scan for homepage modules
