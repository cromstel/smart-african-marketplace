# Order Issue Handling Runbook

This runbook defines handling for delivery, fulfillment, and order-state issues.

## Issue Types
- Late delivery
- Missing or damaged item
- Incorrect item received
- Stuck order status

## Triage Flow
1. Confirm order timeline and current status in system.
2. Check carrier/vendor updates and evidence.
3. Classify severity and assign owner.
4. Resolve via replacement, refund, or status correction.
5. Confirm customer acceptance and close case.

## Escalation
- Escalate to operations lead for repeated vendor/carrier incidents.
- Escalate payment-linked disputes to finance/support owner.

## Reporting
- Weekly summary by issue type and resolution time.
- Top recurring causes fed into vendor performance review.
