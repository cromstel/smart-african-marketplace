# Help Documentation Operations Guide

This guide standardizes how customer help content is maintained.

## Primary Help Surfaces
- FAQ page: `/faq`
- Contact page: `/contact`
- Vendor onboarding guide: `/vendor-guide`
- Checkout and subscription support blocks

## Update Cadence
- Weekly: review top support tickets and add missing FAQ updates
- Monthly: review obsolete answers and links
- Release-based: update help steps when UI/flows change

## Content Quality Rules
- Keep answers task-first and short.
- Use exact UI labels that exist in the product.
- Include escalation path for payment, order, and account lock issues.
- Avoid policy/legal interpretations in FAQ; link to terms/privacy pages.

## Support Escalation Matrix
- Order and fulfillment issues -> support team
- Payment disputes and chargebacks -> finance + support
- Vendor payout/account restrictions -> marketplace operations
- Privacy/legal requests -> legal contacts in policy pages

## Change Checklist
1. Update FAQ entry text in language resources.
2. Validate route links used in answers.
3. Verify translated keys exist for supported locales.
4. Confirm contact CTA is visible on FAQ page.
5. Record updates in release notes.
