# FAQ Update Workflow

This workflow keeps FAQ content aligned with real support demand.

## Inputs
- Weekly support ticket summary
- Top unresolved chat/contact topics
- Recent product or policy changes

## Update Process
1. Rank recurring questions by frequency and impact.
2. Draft/adjust FAQ answers using current UI labels and routes.
3. Validate translations for supported locales.
4. Publish updates and notify support team.

## Verification
- Confirm FAQ entries render on `/faq`.
- Confirm links to contact/vendor guide still resolve.
- Track reduction in repeat support questions for updated topics.
