# GDPR Compliance Checklist

This checklist defines minimum recurring GDPR controls.

## Data Governance
- Maintain data inventory and processing purposes.
- Record lawful basis for each processing activity.
- Keep retention rules documented and enforced.

## User Rights Operations
- Access request workflow
- Rectification and deletion workflow
- Data portability/export workflow
- Objection and marketing opt-out workflow

## Security and Processing
- Apply access controls and least privilege.
- Ensure processor agreements are in place.
- Maintain breach-response notification workflow.

## Review Cadence
- Quarterly internal review
- Immediate review on major feature/data-flow changes

## Evidence
- Completed checklist log with owner/date
- Open gaps with remediation timeline
