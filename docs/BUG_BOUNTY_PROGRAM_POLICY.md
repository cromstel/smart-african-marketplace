# Bug Bounty Program Policy

This policy defines the minimum framework for coordinated vulnerability disclosure.

## Program Scope
- Public web application and APIs
- Authentication, authorization, payment, and data exposure issues
- Excludes social engineering, DDoS, and physical attacks

## Submission Requirements
- Clear reproduction steps
- Impact description and affected endpoints
- Proof-of-concept evidence (non-destructive)
- Contact details for follow-up

## Safe Harbor
- Researchers acting in good faith and within scope are authorized to test.
- No exfiltration, privacy breach, or service disruption is permitted.

## Triage and Response Targets
- Acknowledge report within 3 business days
- Initial severity decision within 7 business days
- Remediation target based on severity

## Reward Guidelines
- Critical: highest reward tier
- High: high reward tier
- Medium/Low: discretionary rewards

## Disclosure
- Coordinated disclosure after fix deployment or agreed timeline.
