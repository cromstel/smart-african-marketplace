# SEO Content Creation Workflow

This workflow standardizes SEO-driven content production.

## Monthly Plan
- Build keyword cluster map by category and intent.
- Assign target pages/posts with owner and deadline.

## Content Process
1. Select keyword and search intent.
2. Draft content with internal links and product relevance.
3. Add metadata title/description and structured headings.
4. Validate readability and route/link accuracy.
5. Publish and index-check.

## Optimization Cycle
- Review rankings and organic traffic monthly.
- Refresh underperforming content with updated copy and links.

## KPIs
- Organic sessions
- Ranking positions for target terms
- Conversion from organic traffic
