# Customer Inquiry Response SOP

This SOP standardizes intake and response handling for customer inquiries.

## Intake Channels
- Contact form
- Support inbox
- Live chat (if enabled)

## Response Targets
- First response within 24 hours (business days)
- Resolution or clear next-step update within 72 hours

## Workflow
1. Tag inquiry category (order, payment, account, vendor, technical).
2. Verify account/order context before responding.
3. Provide direct answer or escalate with ticket owner.
4. Log outcome and response timestamp.
5. Close ticket only after user confirmation or completion criteria.

## QA Rules
- Use approved templates for consistency.
- Include escalation path when issue is blocked.
- Avoid legal interpretation; route to policy/legal owner.
