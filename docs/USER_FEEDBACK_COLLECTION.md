# User Feedback Collection Playbook

This playbook defines consistent collection and triage of user feedback.

## Feedback Sources
- Contact form submissions
- Support inbox and chat
- Product reviews and ratings
- Vendor onboarding/support requests

## Categorization
- Bug report
- Feature request
- UX friction
- Billing/payout issue
- Content/policy concern

## Weekly Operating Cycle
1. Aggregate feedback from all channels.
2. Tag by category and affected area.
3. Score by frequency and business impact.
4. Promote high-impact items to sprint planning.
5. Publish outcomes to product/support stakeholders.

## Metrics
- Top recurring issues by count
- Median first-response time
- Median resolution time
- % feedback items converted to roadmap work

## Governance
- Product manager owns prioritization.
- Support lead owns channel quality and tagging consistency.
- Engineering lead owns technical feasibility review.
